## 三、第6章还能再上一档（可选）

现在是"测算值"。如果你能把下面 3 条 SQL 的**聚合结果**（只有数字，不含任何客户明细）用文字告诉我，第6章就能从"测算"升级为"实测"，论文质量会明显不同：

```sql
-- ① 项目周期分布
SELECT COUNT(*), AVG(actual_end_date - actual_start_date),
       PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY actual_end_date - actual_start_date)
FROM project_timelines WHERE actual_end_date IS NOT NULL;

-- ② 里程碑延误归因
SELECT reason_category, COUNT(*), AVG(diff_days) FROM project_timeline_milestones
WHERE diff_days > 0 GROUP BY reason_category ORDER BY 2 DESC;

-- ③ 返工与响应
SELECT AVG(revision_rounds), AVG(generations), COUNT(*) FROM workflow_kpi;
```

如果确实不能出内网，那第6章就保持现在的写法——**但要能讲清楚"为什么不做统计检验"**，这一版在 6.2 已经把这个理由写成了方法上的自觉选择（数据治理约束 + 证据强度匹配），答辩时可以正面回应。
