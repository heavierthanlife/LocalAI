## 二、内容重排策略（解决"内容丑"）

1. **标题只留 4–5 个字**（模板标题框仅 3.34 in 宽，超过 8 字会换行破版）：研究背景 / 研究问题 / 研究方法 / 理论基础 / 文献综述 / 概念界定 / 现状分析 / 问题诊断 / 成因分析 / 方案设计 / 对象模型 / 环节再造 / 功能模块 / 实施推广 / 效果评估 / 实测结果 / 情景测算 / 结论与展望。
2. **每页 4 条要点**，每条 ≤30 字，加粗小标题 + 正文，20pt→19pt 排布，四行刚好落满模板的圆角文本框。
3. **模板底部的"关键词"五个坑位**全部填成 2–4 字标签（如"数字经济/电子招投标/公平竞争/同质化/流程再造"），不再是"关键词1…5"。
4. **图片页**用模板自带的"左图右文"版式，左图换成论文图（图2.1/3.4/5.1/5.2/6.3），右侧填一句结论，底部填图题。
5. **页脚日期位**（模板原"JUNE 12th"）改为页码（05、06…）。

## 四、使用提醒

1. 打开后 `文件 → 导出 → 创建 PDF`，现场用 PDF。
2. 模板字体为思源宋体 Heavy（标题）与微软雅黑（正文）；换电脑缺字体时以 PDF 为准。
3. 页码是正文内容（写在模板日期位），增删页后手动改。
4. 论文图已按模板图片位等比缩放，未拉伸、未裁切。
5. 若某页文字嫌多/嫌少，告诉我页码，我只改文字、不碰模板。
