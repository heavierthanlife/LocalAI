## 5. 量化体系与"升级为实测"的路径

第6章现在是**测算值**（因为公司数据不出内网，不能导出）。指标体系（表6-1，5 准则 × 17 指标）已经给了每个指标的**测量口径与数据来源**，随时可用。

**若哪天能导数据，第 6 章可从"测算"升级为"实测"**，只需要下面 3 条 SQL 的聚合结果（只要数字，不含客户明细）：

```sql
-- ① 项目周期分布
SELECT COUNT(*), AVG(actual_end_date - actual_start_date),
       PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY actual_end_date - actual_start_date)
FROM project_timelines WHERE actual_end_date IS NOT NULL;

-- ② 里程碑延误归因（论文里"流程冗余/外部脱节"的实证证据）
SELECT reason_category, COUNT(*), AVG(diff_days)
FROM project_timeline_milestones WHERE diff_days > 0
GROUP BY reason_category ORDER BY 2 DESC;

-- ③ 返工强度与任务响应
SELECT AVG(revision_rounds), AVG(generations), COUNT(*) FROM workflow_kpi;
SELECT AVG(EXTRACT(EPOCH FROM (done_at - created_at))/3600.0) FROM project_todos WHERE done_at IS NOT NULL;
```

**当前测算结论**（表6-2、图6-2）：
- 保守：周期 −8%、清标耗时 −18%、返工 −20%、人工搬运 −25%，综合指数 91.5
- 基准：周期 **−15%**、清标耗时 **−32%**、返工 **−40%**、人工搬运 **−45%**，综合指数 **84.2**
- 乐观：周期 −22%、清标 −45%、返工 −55%、搬运 −60%，综合指数 77.8
- 敏感性：参数扰动后综合指数 [81.0, 88.6]；权重 ±20% 扰动后 [82.9, 85.6]，结论方向不变
