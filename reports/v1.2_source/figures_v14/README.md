# figures_v14 —— v1.4 图件重制包（按“Word 中插入 15 cm 宽”1:1 出图）

作者反馈 v1.2 中“图的字和图案都太小、注释应放在图外”。本包按**最终插入尺寸**重制全部 16 张 matplotlib 图：画布宽度固定 5.906 in（=15 cm），因此**图中 fontsize 的 pt 数就是读者看到的 pt 数**；同时删除图内全部“注：…”脚注。

- **生成脚本**：`build/make_figures_v14.py`（新建，一次性生成 16 张；未修改 `figures_final/`、`text_part*.py`、`build_v11.py`）
- **运行**：
  ```
  docker run --rm -v "/path/review:/w" -w /w/build -e PYTHONPATH=/w/pylibs \
    -e MPLCONFIGDIR=/w/.mplcache --entrypoint python local-ai:latest make_figures_v14.py
  ```
- **自检脚本**：`figures_v14/_selfcheck_v14.py`（可重复运行；图元级校验，见第三节）
- 字体：SimHei（`/w/fonts/simhei.ttf`，`addfont` 注册）；300 dpi；`savefig.bbox="tight"`、`pad_inches=0`。

## 一、字号与线宽规范（全部 16 张统一）

| 元素 | 字号 | 说明 |
|---|---|---|
| 正文/标签/图例/数据标注/框内文字 | **12 pt** | 在 15 cm 插入宽度下实际 12.0–13.4 pt（见下表，按 PNG 实际宽度折算） |
| 坐标轴刻度 | 11 pt | 仅刻度数字/分类标签 |
| 子图标题 / 图内分区标题 | **13 pt** | 如“(a) …”“流程效率”“接入层” |
| 图内主标题 / 目标层 | 15–16 pt | 如“分业务类型平均返工轮次（实测基线）”“再造前后关键指标对比（实测）” |
| 线宽 / 箭头 / 边框 | 1.4–1.6 × | 基础线宽 1.7（原脚本 1.1–1.2），箭头 mutation_scale 13、箭头线宽同倍加粗 |
| 柱宽/间距/标记 | 相应放大 | 柱宽 0.52–0.64，误差棒 capsize 4、capthick 1.6，marker ms 10 |

**技术实现**：所有示意图改为“等比例单位画布”（100 单位 = 15 cm，1 单位 = 0.059 in），文字宽度用 `TextToPath`（字体 advance，与渲染一致）实测后自动换行（`wrap()`），框高按行数计算（`bh()`），因此不会出现文字挤出框外；柱状图直接按 15 cm 画布设置 `figsize` 与 `rcParams`。
