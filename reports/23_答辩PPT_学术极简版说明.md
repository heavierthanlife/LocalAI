## 一、参考的三个"学术 PPT skill"

| Skill / 传统 | 核心主张 | 本版怎么用 |
|---|---|---|
| **Tufte slide design**（Edward Tufte《The Visual Display of Quantitative Information》衍生的演示方法） | 数据优先；**数据墨水比**尽量接近 1；删掉非数据墨水（装饰框、渐变、3D、重底色）；"混乱是设计问题，不是信息问题" | 去掉深色标题条、照片背景、装饰色块；表格改浅灰表头；图占主位；页面上只留必要线条 |
| **Beamer Metropolis**（Matthias Vogelgesang, 2015，学术会议最常用的极简 LaTeX 主题） | 拒绝"学术装饰"；细线、克制配色、16:9、大量留白、内容优先 | 细线网格、单一强调色、上下细线分隔、小字号页眉上下文、页码低调 |
| **Swiss / International Typographic Style**（Josef Müller-Brockmann 网格系统） | 模块化网格；非对称布局；字号层级即视觉层级；无衬线/衬线对比；"网格是思考工具" | 统一 12 栏边距（左右 0.62 in）、衬线标题（宋体）+ 无衬线正文（微软雅黑）、左对齐非对称、字号层级 40/32/20/14/11/8.5 |

参考文献与延伸阅读：
- Tufte principles：[jtr13 Tufte's Principles of Data-Ink](https://jtr13.github.io/cc19/tuftes-principles-of-data-ink.html)、[Tufte slide design skill](https://lobehub.com/skills/ingpoc-skills-tufte-slide-design)
- Metropolis：[Moloch: A Revival of the Metropolis Theme](https://jolars.co/blog/2024-05-30-moloch)、[Beamer Metropolis](https://www.sarmate.net/template/beamer-metropolis?lang=en)
- Swiss style：[Swiss Style (Wikipedia)](https://en.wikipedia.org/wiki/Swiss_Style_(design))、[Müller-Brockmann 与网格](https://www.thegraphicdesignschool.com/design-history/joseph-mueller-brockmann)

## 二、本版的具体设计规则

| 项目 | 设定 |
|---|---|
| 底色 | 纯白（不用照片、不用色块背景） |
| 主色 | 墨黑蓝 **#16202B**（正文与标题） |
| 强调色 | 砖红 **#9E2B25**，全篇只用于：标题下 0.85 in 短横线、卡片顶部 0.05 in 线、分隔页编号短线、封面竖线 |
| 辅助灰 | #6B7A8A / #9AA6B2 / #DDE3E8（线条） |
| 标题字体 | **宋体加粗**（学术衬线感），封面 40pt、分隔页 32pt、内容页 20pt |
| 正文字体 | 微软雅黑 11–14pt，行距 1.25–1.3 |
| 网格 | 左右边距 0.62 in；页眉细线在 1.34 in；页脚细线在 7.02 in；内容区 1.5–6.95 in |
| 页眉 | 小字上下文（副标题或"中国石油大学（北京）·MBA学位论文答辩"）+ 标题 + 细线 |
| 页脚 | 论文题目 | 姓名 | 学号 + 页码 |
| 分隔页 | 巨型灰色编号（88pt 宋体）+ PART 小字 + 标题 + 英文 + 短线 |
| 封面 | 左竖线 + 小字"硕士学位论文答辩·MBA" + 40pt 宋体题目 + 英文题名 + 细线 + 三行信息 |
| 结束页 | "谢谢各位老师 / 恳请批评指正"+ 信息，无照片无大字报 |

## 四、三个版本怎么选

| 版本 | 观感 | 适用 |
|---|---|---|
| **学术极简版（本版）** | 白底、衬线标题、单一砖红、无照片无装饰 | 预答辩、组会、学术会议；**没有强制校模板时最推荐** |
| 4 号模板版 | 红色满版、校徽、校训页脚 | 学院明确要求"学校统一答辩模板"时 |
| 2 号通用模板版 | 校园照片 + 蓝橙 | 导师偏好"通用模板"、喜欢有学校照片时 |

> 如果学院强制用某一版模板，把本版内容迁入即可——结构、页码、图表、口径完全一致，迁移只需换母版。

## 五、使用提醒

1. **导出 PDF**：`文件 → 导出 → 创建 PDF`；本版全矢量文字，PDF 约 3–4 MB，投影最稳。
2. 字体：标题宋体、正文微软雅黑（Windows 自带，不会缺字）。
3. 页码为静态数字；增删页后手动改。
4. 12 张论文图（画风 A）已等比嵌入，未拉伸；图片本身的白底与本版白底一致，不会出现"图片方块"。
5. 若现场投影偏暗，可把强调色提到 #B03A2E 或把正文调到 12pt（我可以批量改）。
