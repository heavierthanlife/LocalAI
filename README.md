## 三、如何继续（另一台电脑）

1. 克隆仓库（只取本分支）：
   ```bash
   git clone -b mba-thesis git@github.com:heavierthanlife/LocalAI.git
   # 或 git clone -b mba-thesis https://github.com/heavierthanlife/LocalAI.git
   ```
2. 环境：
   - 论文构建只需 Python + `python-docx`（容器镜像 `local-ai:latest` 已含）
   - 图件需要 `matplotlib==3.10.1`（+ numpy）与中文字体 SimHei
   - 运行方式参考 `reports/v1.2_source/README_复现说明.md`
3. 重新生成论文：
   ```bash
   cd build && python build_v11.py
   ```
   > 注意：主稿是基于作者手工修改版 `build/in_author_v12.docx` 做图件替换得到的，直接 `build_v11.py` 会生成不含手工修改的版本；修改正文请改 `text_part*.py` 后重建，或直接在 docx 中改。
